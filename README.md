A one-page newspaper front page summing up Tuesday 17 November 2026's world news in a single 1024×1024 image: 43 stories across 6 continents — 13 illustrated leads, a world map with numbered pins, and 30 one-liners. Every story happened or was first reported on that Tuesday, and contested claims are marked as claims. The page was rendered with Python + PIL from a hand-drawn flat-vector layout (no photos, no AI-generated imagery); the entry program simply copies the finished image to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
